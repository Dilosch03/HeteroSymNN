Type Definitions
================

When building networks in HeteroSymNN, you will frequently pass specific configurations (like activation strings and constants) into your layers. 

To keep the API clean, the framework uses custom type hints to show you exactly what data is expected. This section breaks down those custom types so you know exactly when to pass a string, a dictionary, or a nested tuple.
